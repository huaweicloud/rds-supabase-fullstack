# MCP 场景验收矩阵

这是最终目标矩阵，不代表当前已实现。L=本地单元/协议，I=授权测试云环境，H=目标宿主。每条保存包版本、合成或脱敏输入、工具轨迹、任务关联、实际与预期结果；不保存秘密。

| ID | 场景与前置 | 输入/操作 | 必须满足 | 验证层 |
|---|---|---|---|---|
| M01-01 | 已有可管理 PG | 选择已有 PG 创建 | 正确关联；不新增 PG；受理、终态和应用回查分开 | L/I |
| M01-02 | 新建 PG 可用组合 | 新 PG 创建路径 | 参数组合合法；记录后端实际产生资源；失败报告保留项 | L/I |
| M01-03 | 有实时候选 | 开发/生产用途及用户覆盖 | 推荐有依据；显式覆盖优先；无价格证据不报价 | L/I |
| M01-04 | 额外要求 | 工具未支持字段或必要能力 | 未知参数拒绝；必要条件未满足不提交；不隐式丢字段 | L/H |
| M02-01 | 可删应用关联 PG | 仅删除应用 | PG 保留；应用删除结果和任务均核对 | L/I |
| M02-02 | PG 多应用关联 | 请求级联删除 | 完整影响清单、保护检查、明确确认；不默认级联 | L/I/H |
| M03-01 | 可绑定 EIP | 绑定/解绑 | ID/IPv4正确；计费/中断提示；实际关联回查 | L/I |
| M03-02 | 适用证书 | SSL 开/关 | 关闭 cert_id=null；私钥由后端处理；关联 URL 手动检查 | L/I/H |
| M03-03 | 安全输入可用 | 修改应用密码 | 仅目标账号；秘密不进入模型/日志；不承诺回滚 | L/I/H |
| M04-01 | 目标安全组 | 查询、建组、增删规则 | 正确接口版本；8443明确来源；保留无关规则 | L/I |
| M04-02 | 共享安全组/重复规则 | 同规则或共享修改 | 无重复新增；展示共享影响；删除准确规则 | L/I |
| M05-01 | 应用与 Key 归属明确 | 分页/过滤列表 | limit 1–100、offset≥0；仅元数据；无明文 | L/I |
| M05-02 | 安全展示通道可用 | 查看值 | 独立授权、归属/状态校验、审计；不进入普通输出 | L/I/H |
| M05-03 | normal Key | 重置 | 预览确认；新记录需可靠关联；任务和记录切换分别验证 | L/I/H |
| M06-01 | Auth 配置存在 | 仅修改一个字段 | 未提供/null保留；不回填密钥占位；不误清空其他配置 | L/I |
| M06-02 | OBS/SMTP/GitHub | 启用、修改、关闭 | 分别按契约处理依赖和秘密；保存不等于外部连通 | L/I/H |
| X01 | 已生成计划 | 改目标/参数/身份/过期重用 | 拒绝提交；要求重新规划和确认 | L/I |
| X02 | prepared 计划 | 取消后提交/重启后提交 | 取消持久化，旧计划不可提交；无云调用 | L |
| X03 | 已 claim/accepted/unknown | 取消或重复提交 | 不假报云取消；同意图不重放；保留记录 | L/I |
| X04 | 并发调用 | 同计划两次提交或取消竞争 | 原子决出；最多一次写请求 | L |
| X05 | 响应丢失/超时 | 写后查询记录 | 标记未知；不自动重试；任务/资源证据核对 | L/I |
| X06 | 后端 202/未知状态 | 查询任务 | 不报完成；未知枚举保留为未核实；有界查询 | L/I |
| X07 | 无权限/只读/受保护 | 任一写操作 | 无云写请求；不能旁路执行 | L/I |
| X08 | 多步中间失败 | 查询执行记录 | 原有与新建资源区分；不自动删原有资源 | L/I |
| X09 | REST→SDK 同一输入 | 适配器契约回归 | 参数、错误、结果及无盲目重试行为一致 | L/I |

验收分 MCP 独立、Skill 独立、真实组合三层；模拟通过不替代 I/H。支持能力逐项验收，未满足项记录为未通过/未验证，不改写为范围外。
