# 0.3.8a1 六场景核心工具增量

日期：2026-11-07。开发预发行版；不宣称六场景全量生产验收完成。

相对0.3.7a1新增12个工具，总计29个：Single创建（已有PG/按需新PG）、Supabase规格和可托管PG查询、应用改密、完整已知Auth配置、OBS更新、VPC组查询/创建及规则增删、指定ApiKey本地文件交付。专项Skill独立位于skills/huaweicloud-supabase。

安全机制：本地受保护请求别名、秘密脱敏预览、两阶段确认、请求内容绑定、一次提交、未知结果持久记录、只读/保护规则。Storage首次启用需SK，已启用同AK可省略；Key明文不返回模型，文件由可信用户查看/复制。

验证：124项pytest通过，覆盖率93.09%（含stdio子进程），保留80%门槛；Skill格式校验、离线诊断和wheel构建另随交付核对。进行了独立代码审查，未发现确认的阻断性问题。未调用业务云API，未修改用户AK/SK。没有将原始SDK资料或内部交接包提交公开仓。

重要边界：
- 应用仅Single；不自动支持Ha、包周期支付和tags。容量、PG版本下限、密码策略、规格可售与配额由后端权威校验，须在真实环境验证。
- 删除只删应用保留PG；没有应用→PG级联接口，不能用反向删PG模拟。
- 证书选择/购买需CCM外部流程；未提供原生发现或自动购买。
- VPC共享关联全集和资源挂载须人工核对；新Key与reset job自动关联未闭合。
- Windows ACL由操作方配置；本地文件不是宿主秘密保险库。同权限Agent/Shell必须通过运行账户/宿主隔离限制。
- TLS跳过补丁未合入。SDK依赖安全策略、Windows新版本、实际Agent场景和码道联合验收仍是发布门槛。
- 本地账本不等于云侧幂等。除了Auth注册开关的已有reconcile流程，新动作的accepted/unknown不自动解锁，禁止删账本或换机器重放。
