# 需求一：Supabase 本地管控 MCP Server

版本 v0.4；2026-11-02；需求责任人、需求单、交付局点及发布窗口由项目负责人补录。对应验收编号见 ACCEPTANCE.md；待确认项统一见 OPEN_QUESTIONS.md。

## 背景与目标

为用户通过 AI 助手管理华为云 Supabase 提供标准工具，减少控制台逐页操作，保证资源定位、参数检查、确认、执行及结果验证可追溯。不提供此能力时，Agent 无法可靠完成云管控诉求，客户仍须手工操作并自行核对结果。

交付包含本地 MCP 安装包、版本化工具契约、配置与权限说明、场景测试、联调执行单、码道接入材料和已知限制。业务鉴权与租户隔离最终由后端强制执行，不能依赖客户可修改的本地程序。

## 功能范围

| ID | 场景 | 目标能力 | 边界 |
|---|---|---|---|
| M01 | 创建 | 两条路径：已有 PG、新建 PG；查询 Region/AZ、规格、参数模板、企业项目、时区、VPC/子网/安全组；按用途建议并创建 | 规格以实时候选为准；新建 PG 是否由单个后端请求编排以契约为准，不擅自拆成多次创建 |
| M02 | 删除 | 仅删应用保留 PG；明确授权下处理关联 PG 级联删除 | 展示关联应用和共享影响；禁止默认删除 PG；未有完整影响清单不能启用级联 |
| M03 | 访问 | EIP 绑定/解绑、SSL 开关、适用证书查询选择及购买引导、Supabase 账号改密 | 新购 EIP/自动购买证书需独立范围及契约；不修改其他 PG 账号，不收集证书私钥 |
| M04 | 安全组 | 列表、详情、创建、规则增删/调整；检查 TCP 8443 | 依据实际应用端口核验；显式来源，不默认全网；共享影响与无关规则保留；不扩展整组删除 |
| M05 | ApiKey | 元数据分页查询、受控查看明文、重置、结果核对 | 复制为客户端行为；新旧 Key ID 不等同；安全交付路径未具备时不开放明文工具 |
| M06 | 业务配置 | OBS、SMTP、邮件模板、GitHub OAuth；查询/局部修改/明确关闭 | 按字段区分不传、null、空串、关闭；不同配置接口的保留语义不得互推 |

## 默认选配与要求覆盖

选配依据：用户用途、预算倾向、可用性要求、已有资源，加上实时可售和兼容信息。规则应有版本与选择理由，不宣称低配必然适合生产。费用无报价依据时明确未知。
用户每项明确要求必须映射为：本次满足、后续步骤、当前不支持、待澄清。必要条件未满足时不提交；用户接受调整后重新生成方案。工具对未知参数拒绝，不静默忽略、不透传任意 JSON。未来需求覆盖表仅存非敏感结构化要求，不存秘密。

## 架构与执行安全

工具层 → 场景服务 → 客户端适配层；REST 与 UniSDK 实现同一业务契约，通过请求/结果/错误/重试语义回归验证迁移。工具不等同 API 清单，不提供通用 HTTP/Shell 绕过入口。

所有写操作有方案预览；方案绑定应用、项目、服务地址、操作、规范化参数和身份上下文，有效期 10 分钟，一次使用。客户端负责真实用户确认，MCP 验证方案有效性，confirm 布尔值不能证明人类确认。执行前重新核对资源状态/保护规则；目标或关键配置变化需重规划。当前状态快照绑定尚需后续实现，不混同参数摘要绑定。

元数据只读可以直接执行；敏感读取仍需要明确授权。未知结果不能自动重试写请求。提交前可取消本地方案；提交后取消对话不等于取消云任务。并发取消/提交应原子决出，只有一个成功。

## 状态与恢复

分别报告请求受理、任务状态、资源状态、业务验证状态，不能用一个 success 覆盖四层。未核实终态映射时返回未知，不因资源暂时 normal 宣称全任务完成。具体状态与恢复流程见 RECOVERY.md。

多步操作记录资源来源（原有/本次创建）、已完成动作与待办。失败时禁止默认删除用户原有资源；清理需预先覆盖的授权或新的确认。Key 重置、密码修改、删除不承诺自动回滚。

## 凭据、权限与配置

目标沿用 GaussDB 的环境变量、MCP 专用文件、devkit 凭据复用方向，支持临时凭据；实际接入以测试环境鉴权契约为准。Skill 不收集 AK/SK。应用配置秘密与云调用身份分离，采用本地引用/可信输入。未完成客户端安全通道前，不开放秘密写入与明文输出。
日志和交付禁止秘密；输出目标采用已确认字段白名单。错误应保留安全的请求关联信息，不透出原始响应、内部地址或凭据。当前启发式脱敏不是最终白名单验收。

## 发布、升级与回退

本地 MCP 与业务云服务分别升级。升级不自动重放写操作；保持账本，进行数据库兼容检查与备份。SDK 替换按能力开关/固定版本验证，不自动将失败请求切换另一适配器重发。
客户端回退可关闭写开关或回退兼容包；不能撤销已提交云任务，也不能将包版本回退描述为业务数据回滚。未确认账本兼容性时禁止直接降级。

竞品分析另行基于可核实资料补充，当前不作性能或能力领先结论。正式局点、版本/实例类型/状态限制依赖后端契约，未知限制作为发布门槛，不填推测值。

## 2026-11-07 SDK基线更新
当前应用模式仅Single，拒绝Ha。创建交付受限于已有PG或postPaid新PG；默认选配只基于实时候选，版本/容量/密码/免费规格政策后端最终校验。包周期、tags、全自动网络资源选配另行验收。应用删除接口始终只删应用保留PG；原始目标中的级联不能从该接口实现，需独立变更范围。

增加本地引用式秘密输入及本地文件式ApiKey交付，不让模型接触明文；Windows ACL由操作方建立，不能将其描述为已经具备码道秘密控件。Storage首次启用要求SK，已启用且同AK可省略保留。MCP确定性验收见SIX_SCENARIO_MATRIX.md，本次不以文档或单元测试代替真实场景验收。
