# 技能反馈

当用户报告本技能给出错误指导、缺少信息或可以改进时使用本流程。反馈对象是技能本身（agent 指令），而非平台产品。

## 步骤

1. **征得同意**——询问用户是否愿意向技能维护者提交反馈；用户拒绝则终止流程。

2. **起草**——按 [assets/feedback-issue-template.md](../assets/feedback-issue-template.md) 结构化填写。必须定位到引发问题的具体文件与章节。

3. **提交**——在 `huaweicloud/rds-supabase-fullstack` 仓库创建 GitHub Issue，标题格式必须为 `user-feedback: <问题摘要>`。

4. **回传结果**——把 Issue URL 告知用户。提交失败或仓库不可访问时，将草稿直接转交维护者。
